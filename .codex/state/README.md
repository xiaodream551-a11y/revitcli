# .codex/state/

This directory is intentionally mostly gitignored. It stores temporary Codex
working notes such as ad-hoc reviews, delegation scratch files, and diagnostic
logs.

Do not treat files here as durable project truth. Durable agent rules live in
`.codex/CONTRACT.md`, `.codex/config.toml`, and `.codex/agents/*.toml`.

The `.gitkeep` keeps the directory present in fresh clones.
